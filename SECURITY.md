# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it responsibly.

**Do NOT open a public issue.**

Instead, send an email to the repository owner or use [GitHub's private vulnerability reporting](https://github.com/henchoznoe/NexTemplate/security/advisories/new).

Please include:

- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (if any)

You will receive a response within 72 hours acknowledging receipt. A fix will be prioritized based on severity.

## Supported Versions

Only the latest release is supported with security updates.
